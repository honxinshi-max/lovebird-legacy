# 牡丹鹦鹉育种社会 · 首个可玩切片

这是一个本地运行的 2D 网页原型，用来验证游戏最核心的玩家任务：研究种鸟、比较配对、理解遗传结果、留下有明确理由的幼鸟，并让这条血系进入第二代。

它不是完整经营社交游戏，也不包含登录、充值、市场、Club、训练、比赛或官方新品种认证。当前物种兼容率、遗传稳定度和健康风险参数是**待专业复核的游戏规则**，不能视为真实鸟类繁育建议。

## 运行

需要 Node.js 22 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址，通常为 `http://127.0.0.1:5173/`。

## 验证

```bash
npm test
npm run build
```

自动化测试覆盖确定性随机、物种规则、遗传重组、表型取舍、近交风险、原子繁育、不可变历史、存档并发控制、两代应用命令和完整 UI 流程。

真实浏览器验证使用项目环境提供的 Playwright CLI 完成，包含 1440×900 桌面主流程、刷新恢复、1024×768 平板鸟舍、控制台与横向溢出检查。结果和截图见[浏览器 QA 回执](docs/verification/2026-08-29-browser-qa.md)。

## 已实现的第一步

- 3 个基础物种、6 只固定种鸟、12 个离散基因位点。
- 6 组性能潜力、5 组性格倾向，以及显式机会成本；没有综合战力或最佳配对按钮。
- 显隐性、稳定单倍型块、重组、小概率突变、亲本来源解释。
- 生殖兼容、年龄/健康/冷却/次数限制、共同祖先和隐性健康风险预审。
- 同窝 3 只幼鸟、结构化留鸟理由、第二代异种有限兼容繁育。
- 不可变身份和血统、追加式历史、确定性重放校验、IndexedDB 本地恢复。
- 基因驱动的分层 SVG 鸟形象，以及共享呼吸、眨眼和歪头动画。
- 仅保存在本设备的行为反馈账本，为目标玩家试玩复盘提供数据。

## 产品边界

当前完成的是“技术上可玩的核心价值假设”，不是市场验证。下一道产品门槛是让至少 5 名目标玩家完成试玩，并观察他们能否提出不依赖最高总数值的留鸟理由。若大多数玩家仍只追逐同一数值，应该先重做取舍与解释结构，不应扩展经济、市场或 Club。

设计依据见[垂直切片设计](docs/superpowers/specs/2026-08-29-lovebird-breeding-vertical-slice-design.md)，实现拆解见[实施计划](docs/superpowers/plans/2026-08-29-lovebird-breeding-vertical-slice.md)。
